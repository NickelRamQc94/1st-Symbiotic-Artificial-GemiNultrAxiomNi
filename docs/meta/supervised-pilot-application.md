# Supervised Pilot — Autofocus Smart Glasses

**Applicant:** Nickel David Grenier, QC  
**Program:** Meta Wearables Accessibility  
**Duration:** 90 days

## Clinical profile
- Bilateral optic disc drusen
- Mixed astigmatism and +6.00 D reading correction
- History of bacterial corneal ulcer/keratitis and photophobia
- Contact lenses medically contraindicated

## Neurocognitive profile
ADHD Combined (DSM-5-TR 314.01), biphasic CPT-3 performance, and severe time blindness. Reported results should be reviewed and confirmed by qualified clinicians before being used for medical or program decisions.

## Operational need
High-density AI user requiring adaptive visual assistance; static interfaces are not consistently usable.

## Proposed protocol
- **Weeks 1–2:** Clinical/optical calibration, IXI/ViXion evaluation, and SDK integration.
- **Weeks 3–12:** Daily logs, bi-weekly reports, and biphasic performance testing.
- **Safety:** Stop testing for worsening photophobia, redness, pain, vision changes, or clinician-defined intraocular-pressure concerns; perform scheduled ophthalmological reviews.

## Value to Meta
A supervised pilot could provide structured accessibility data from an uncommon visual and neurocognitive profile while prioritizing participant safety and informed consent.
